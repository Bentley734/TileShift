## Install

1. Import the donor games into Gen1Recomp: **Emerald and FireRed** for the Gen 3
   theme, **Red and Crystal** for full Gen 1 theme coverage, and **Crystal** for the Gen 2 theme.
   The Crystal theme also reads the original Cerulean bicycles used in Mauville and Cerulean from **Red**.
   TileShift reads native donor
   art from your own imports; neither ROMs nor extracted native artwork are
   bundled.
2. Download `TileShift-v0.45.1.zip` from [the latest release](https://github.com/Bentley734/TileShift/releases/latest).
3. Extract the `tileshift` folder into Gen1Recomp's `mods` directory, enable
   **TileShift**, and restart the game.
4. Open Options and select **Tileset**. Gen 1/2 hosts offer **Gen 3**; Gen 3 hosts
   also offer **Gen 1** and **Gen 2**. **Original** restores the host game's art.
   Fresh installations retain the existing Gen 3 default.

Requires **Gen1Recomp 0.3.96 or newer**; validated on 0.4.0. There is no maximum launcher version requirement. Reviewed replacements
support all eleven games. Gen 3 hosts keep their native art with the Gen 3 style
selected. Missing or changed donor cells are skipped, leaving the
host artwork visible.

The release also includes
`TileShift-Gen1-Gen2-All-Areas-Comparisons-v0.32.0.zip`: **1,791 side-by-side
images**, covering every imported town, interior, route and other area in Red,
Blue, Yellow, Gold, Silver and Crystal. Open `index.html` after extracting it to
browse by game and area. Images use actual native background renders and state
their replacement counts. The two unused Gold/Silver Safari Beta maps are
included with their retained native graphics. This is a historical v0.32.0
snapshot; its side-entrance markers predate the v0.34 direction fixes.
The [v0.34 fixes gallery](https://github.com/Bentley734/TileShift/releases/download/v0.34.0/TileShift-Gen2-Fixes-Comparisons-v0.34.0.zip)
contains native captures of the corrected entrances and live background refresh,
plus the reproduced overlap before the fix. A separate
`TileShift-Gen2-in-Gen3-Comparisons-v0.35.0.zip` shows this release's Crystal-theme
changes on GBA maps, including partial routes with native tiles still visible.
`TileShift-Mart-Roof-Fixes-Comparisons-v0.35.0.zip` contains fresh native captures
of all 39 affected Mart exterior maps across Gold, Silver and Crystal.
`TileShift-Crystal-Berry-Comparisons-v0.35.0.zip` shows all 43 plants and their
nine frames through the actual native berry actor renderer. These are isolated
actor atlas fixtures, rather than map or interactive growth captures.

**Flowers**, **Tall Grass** and **Water** independently. Each offers **Default**,
numbered designs, **Random** (one design for the session) and **Mixed** (one stable style per connected area). Edge- and corner-touching
tiles in the same category share one design; separate patches can vary. There are 87 small-tree/shrub choices, 89 Big

above fixed trunks. Grass foregrounds follow the same animation around actors.

only disturbed grass cells animate and then settle. Grass and flower foregrounds
cover characters’ feet with their own matching plant pixels, retaining visible

## Performance

Warm map lookups reuse indexed map tables without rebuilding row lists or
allocating cache keys. Ownership uses the engine's constant-time owner epoch;
import-marker polling runs once per second outside rendering. Cosmetic choices
retain the donor decoder cache. Connected-area grouping runs only when a map's
visual replacements are built. Actor bindings inspect list identity/count and
appended entries; unchanged frames do not run another full entity scan.
The Gen 2 adapter checks attached current/neighbor canvas identities before
ground drawing. Unchanged frames reuse those references without new bakes or
file reads; enabling, reloading or changing themes refreshes stale references.
The Gen 3 adapter caches atlas slots and animation schedules. Unchanged draws
do not allocate images or copy unchanged atlas planes; native animation and
palette writes dirty only the affected slots. Switching back to Original restores
the current native atlas pixels.
